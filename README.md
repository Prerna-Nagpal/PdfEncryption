# 🔒 PDF Encryption Project using Python

This project demonstrates how to **encrypt PDF files using Python** with the [`PyPDF2`](https://pypi.org/project/PyPDF2/) library.

---

## 📂 Project Structure

| File | Description |
|------|-------------|
| `PdfPasswordProtection.ipynb` | Jupyter Notebook to encrypt PDF files |
| `Report.pdf` | Original PDF file to be encrypted |
| `encryptedreport.pdf` | Output encrypted PDF with password protection |

---

## ⚙️ How It Works

1. Load the original PDF.
2. Define a password to protect the file.
3. Use PyPDF2 to encrypt it.
4. Save the encrypted PDF as a new file.

- PyPDF2
